# 五人 / 六人不完全信息学习 AI（实验版）

支持五人找朋友与六人隔座固定队，共用一个小型神经网络，以模式、相对座位和公开历史区分玩法。
这是可以训练、评测并显式接入服务器的研究基线，**不是已经达到近似最优或超越大师的成品**。
默认服务器仍使用原来的 AI；没有模型文件也可以照常启动。

## 模型实际学习什么

- **出牌价值**：输入自己可见的状态和候选出牌，预测最终净升级收益（除以 3）。从候选中选择预测收益最高的动作。
- **隐藏牌估计**：辅助预测其他座位和未知底牌中 54 种牌面的期望张数。隐藏牌只作为离线训练标签。
- **行为预测**：辅助预测其他玩家下一次出牌的 8 个粗粒度类别，包括单张、对子、三条、拖拉机、甩牌与毙牌等。这是行为预测，不是对心理意图的识别。

网络由共享状态编码器、动作价值头、隐藏牌头、行为分类头组成。辅助任务通过共享编码器影响出牌价值；没有把真实隐藏牌或未来动作作为输入。
历史输入包括每人的累计出牌、缺门、行为频率以及最近 8 次动作的顺序特征。
当前实现是 NumPy 的小型前馈网络，不是 Transformer，也没有使用 GPU。

## 信息边界

`src/ai/learning/observation.js` 是从完整牌局进入模型的唯一入口。
它创建脱离原对象的白名单视图：自己的手牌、公共叫主和出牌、各家手牌张数、公开分数和身份。
只有庄家可以看到自己扣下的底牌。五人朋友未揭晓时 `friendSeat` 保持未知；不能仅因持有一张被叫牌就断定身份。
候选动作生成也使用脱敏视图，避免动作集合泄漏别人的牌。

观测编码不使用牌的唯一 ID 或副牌编号，只编码牌面和数量。真实卡牌 ID 仅用于把自己的动作交给规则引擎。
模型不会读取真人身份或跨局玩家资料，因此目前只适应本局行为。可选的本地真人对局采集与自动训练见 [automatic-learning.md](automatic-learning.md)；普通启动默认不采集。

离线模拟器知道隐藏牌，用于计算辅助监督目标和最终奖励。训练目标与观测存放在不同字段。
五人奖励按终局实际朋友身份计算；六人按与庄家座位的奇偶关系计算。

## 训练

运行要求：Node.js >=20、Python >=3.10、NumPy。训练不改变线上服务。

```sh
python -m pip install -r bench/learning/requirements.txt
python bench/learning/train.py --iterations 4 --games 64 --epochs 3 --out .run/learning-smoke
```

每次迭代一半五人、一半六人。六人同时覆盖首局抢庄和不同等级续局。
第一批数据来自规则/随机策略，后续加入当前模型的 epsilon-greedy 自对弈、简单/困难规则对手及旧模型产生的轨迹。
保留最近三轮回放，使用终局蒙特卡洛回报训练价值函数，以 Adam 更新网络。
旧模型在部分整局中替代当前模型生成回放，并非每个座位都有独立的历史模型池。

训练目录包含：

- `candidate.json`：最新实验模型；Node 服务器可直接读取，无需 Python 推理服务。
- `checkpoint-*.json`：各轮权重快照。
- `rollout-*.jsonl`：模拟器生成的训练样本，包含监督标签，**不能作为线上观测传给策略**。
- `training-report.json`：种子、局数、优化步数及训练损失。

必须为每次完整训练指定新目录；已有 `candidate.json` 时拒绝覆盖。
当前未实现优化器断点恢复。扩大训练时可使用例如：

```sh
python bench/learning/train.py --iterations 20 --games 512 --epochs 4 --out .run/learning-long
```

这是训练命令示例，未承诺所需时间或棋力；应先观察本机吞吐与验证结果。

## 独立评测

```sh
node bench/learning/evaluate.mjs --model .run/learning-smoke/candidate.json --seeds 40 --out .run/learning-smoke/evaluation.json
node bench/learning/evaluate.mjs --model .run/learning-smoke/candidate.json --seeds 40 --opponent random
```

评测会检查测试种子没有出现在训练中。对每个牌局分别让模型替换每一个座位，比较相同种子下全规则基线中该座位的终局净升级收益。
所有对手都使用脱敏视图。相同牌局的座位轮换有关联，所以先对轮换取均值，再按独立牌局估计标准误。
输出区间是近似 95% 区间，小样本下不能当作严格显著性证明。
`meanNetworkScoringMs` 只测网络打分，不含观测编码和候选生成。

这衡量单个座位替换的效果，不是全队训练收益，不是对在线大师 PIMC 的胜率，也不是纳什可利用度或真人评测。
负值表示在该基准中比规则基线弱，不应上线替换现有 AI。

## 显式启用实验模型

先完成评测，再在**单独的测试服务器**使用：

```powershell
$env:PORT = '3001'
$env:LEARNED_AI_MODEL = (Resolve-Path '.run/learning-smoke/candidate.json').Path
npm start
```

启用后，仅五人/六人中的“大师”机器人使用学习模型；其他档位、真人托管和四人玩法保持原逻辑。
模型推理失败时先回退 PIMC，再使用既有规则兜底。不设置 `LEARNED_AI_MODEL` 就不会启用实验模型。
模型格式错误会在启动时明确报错，避免误以为已加载成功。

## 检查与限制

```sh
npm test
python -m unittest discover -s bench/learning -p 'test_*.py' -v
```

测试包含开局/中局的隐藏手牌置换不变性、其他手牌读取阻断、底牌隔离、五六人整局合法性、确定性回放、终局身份奖励、同策略零差异评测、梯度数值校验以及 Python/Node 推理一致性。

当前仅学习出牌阶段；叫主、扣底、叫朋友沿用规则策略。候选集合复用引擎的有限候选，不枚举所有组合，因此存在动作空间上限。
输入保留历史摘要而非完整序列网络；未做隐藏牌分布的严格联合约束、校准、信息集树搜索或真人个性化。
`explainDecision` 返回诊断性期望张数和动作类别预测：缺门会被置零，但边际张数不保证满足所有手牌容量约束，不应把它当成真实手牌。
短程训练只能验证学习链路，不能证明强度；更长训练也必须经过未见种子、不同对手和真人回放验证。
