# 牌桌特效

设置位于进入页和牌桌右上角的声音设置中，提供「炸裂／轻量／关闭」，保存到本机浏览器。
系统开启减少动态效果时，即使选择炸裂也使用轻量提示。声音仍由原有语音／音效开关和音量控制，默认关闭。

- 拖拉机与三条拖拉机：写实农机透明素材，金属／轮胎／玻璃细节、车身微震、轮迹和扬尘，配合低频发动机与砂石声。
- 主牌毙牌、反杀：写实火球、短促光照、缓慢扩散的烟尘与弹道火星；反杀有延后的第二层爆破。
- 甩牌成功：带纸面纹理、角标和阴影的扑克牌展开。
- 甩牌失败：纸牌沿不规则边缘撕开，碎片翻落、细小纸屑和 −10 分提示；具体失败原因仍可查看原牌桌提示和日志。
- 三条、大额收分、本局胜利／失败／观战结算：纸牌、金属硬币、写实奖杯和较克制的文字提示。

写实图片位于 `public/effects/*-real-v1.png`，由 imagegen 生成并保留 alpha 透明通道。
只在炸裂模式且页面可见时预加载四张素材；轻量／关闭／减少动态模式不预加载。
纹理、素材和文字均有单独的运动层，避免以放大漫画图标替代真实材质。

升级没有新增独立炸弹牌型。爆破由服务器确认的合法毙牌触发，不会把任意主牌或三条误判为炸弹。
`lastTrickKillSeats` 仅补充刚结束一墩的公开毙牌结果，使最后一手出完即收墩时仍可正确触发。

特效层放在牌桌内，底部预留至少 26%，并随实际手牌／控制区高度扩大；所有节点不接收指针事件，不变更手牌、计分、回合时间或规则。
最多一段正在播放、两段候播，粒子数桌面上限 20、触屏 12。定时清理，不依赖 animationend。
首帧／重连不补播历史；重复状态去重；退出、换桌、后台和切换特效档位会清理动画。
轻量档只显示短暂文字提示，关闭档停止新特效；回合赢家等必要信息仍正常显示。

验证：

```sh
node --test test/table-effects.test.js test/effect-audio.test.js
node scripts/preview-table-effects.mjs /path/to/牌桌特效预览.html
```

预览使用与游戏相同的特效代码、CSS、透明写实素材和音效，打包为单个离线 HTML。
它不连接牌局，不采集训练记录，不修改已运行的服务。
